# Deep Investigation Protocol

Use this skill for complex queries requiring synthesis across multiple disciplines and silos.

## Protocol Steps
1. **Query Decomposition**:
   - Break down the user's inquiry into 2-4 sub-questions.
2. **Multi-Silo Sweep**:
   - Query `notes` for personal perspectives.
   - Query `github` for implementation realities.
   - Query `web` and `pdfs` for external specifications and facts.
3. **Synthesis & Citation**:
   - Assemble the findings into a clear, concise report grounded strictly in the retrieved corpus.
   - Highlight contradictions or gaps if any exist.
